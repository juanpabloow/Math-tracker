# MathPath

Web de seguimiento matemático, adaptable a celulares y computadores.

## Publicar en Vercel

1. Descomprime la carpeta.
2. Sube los archivos a un repositorio de GitHub (raíz del repositorio).
3. En Vercel pulsa **Add New > Project**, importa el repositorio y despliega sin configurar un framework (Other).
4. Abre la URL HTTPS que entrega Vercel en tu celular.
5. En Safari iPhone: Compartir > Agregar a pantalla de inicio. En Chrome Android: menú > Instalar app / Agregar a pantalla principal.

También puedes subir los archivos descomprimidos a Netlify Drop.

## Datos

Los datos se guardan en localStorage del navegador. No hay cuenta ni sincronización entre dispositivos. Usa Exportar/Importar respaldo para transferir o recuperar el avance. No uses navegación privada para guardar el progreso.
